Packages

What the selected generation publishes, resolved through the typesetter's real loader. There is no package manager here and nothing outside the two lists can be fetched — both corpora are compiled into the WebAssembly module.

Switching Lang switches this list, but not what a document can reach: a @require: searches its own generation first and falls back to the other, so a 0.1 document may use a 0.0.6 package and the reverse. That fallback is the port's cross-version bridge, and the last three examples exercise it — one crossing each way, then one crossing it refuses, with the reason.

Versions are byte-verified rather than declared: each bundled file's git blob hash was matched against its upstream repository's release tags. + patch marks a package the typesetter's layout tests carry a local fix to. Every licence text is served beside this page and linked above; LGPL-3.0 incorporates the GPL-3.0 by reference, so that text is here too.

The two fonts at the end of the list are redistributed on the same terms, verbatim and unmodified, each beside its own licence. The Japanese one is not downloaded until a document actually contains Japanese, so a Latin-only session never pays for it.
